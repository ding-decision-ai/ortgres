# Model run records

Recorded model messages, tool calls and tool outputs. Task records, initialization records and additional records are indexed separately. Missing initial inputs and incomplete records remain marked.

Platform session, message and call identifiers use consistent anonymous references; account-plan and quota fields are omitted. Source offsets and hashes refer to the original captures; checksums for these exports are listed in `../SHA256SUMS`.
